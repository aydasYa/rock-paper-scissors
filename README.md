# Rock Paper Scissors - UI
A Rock Paper Scissors browser game with a simple UI. Player and Computer play rounds, each round decides who won. The goal of each player
is to reach 5 points first

## Getting started
To test and play the game, you need to clone this repo, cd into the cloned repo and open the index.html in your browser of choice. Use the following command:
```
git clone https://github.com/aydasYa/rock-paper-scissors.git
cd rock-paper-scissors
```

## How to play
Choose Rock, Paper, or Scissors by clicking a button.
The computer makes a random choice for each round.

The winner of a round receives one point.
A tie awards no points.

The first player to reach five points wins the game.
After the game ends, further clicks do not change the scores
or the result displays.
